
#  University Management System

##  About the Project
The University Management System is a Java-based application designed to manage university activities, student records, faculty information, attendance, fees, and examination results.

##  Features
- Faculty Login
- Student Login
- Student Record Management
- Faculty Leave Management
- Faculty Attendance Management
- Course-wise Fee Management
- Fee Payment Status Tracking
- Marks Entry
- Result Publishing

## Technologies Used
- Java
- MySQL
- Java Swing
- JDBC
- IntelliJ IDEA

##  Requirements
- Java JDK
- MySQL Server
- IntelliJ IDEA
- MySQL JDBC Driver

##  How to Run
1. Clone this repository.
2. Open the project in IntelliJ IDEA.
3. Create the required database in MySQL.
4. Configure the database connection in the Java code.
5. Add the MySQL JDBC driver.
6. Run the main Java class.

## Database
The application uses MySQL to store student records, faculty details, attendance, fees, marks, and examination results.

## Project Objective
The main objective is to simplify university administration by managing student and faculty information in one system.
